# tolyui_rich_input

支持图片、表情、文件和富文本序列化的 Flutter 输入组件。

## Features

- 基于 Flutter Quill 的富文本编辑；
- 支持图片、文件和自定义 Embed；
- 提供表情、提及、链接检测和剪贴板能力；
- 支持编辑内容序列化与恢复。

## Getting started

在 `pubspec.yaml` 中添加 `tolyui_rich_input`，然后执行 `flutter pub get`。

## Usage

```dart
import 'package:tolyui_rich_input/tolyui_rich_input.dart';
```
