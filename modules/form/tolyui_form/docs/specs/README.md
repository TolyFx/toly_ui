# tolyui-form 组件规范

版本：v0.1 · 更新：2026-10-24。

本目录记录 `tolyui_form` 的通用表单组件定义、结构、参数、交互及验收规则。对外讨论名称为 **tolyui-form**，Dart 包名沿用 **tolyui_form**。

规范采用逐项制定的方式，当前包含类型动作选择器和尺寸输入器。编号是稳定引用，不表示 Flutter 组件已经实现或发布。

| 编号 | 组件 | 标识 | 状态 |
| --- | --- | --- | --- |
| F001 | [类型动作选择器](type-action-selector.md) | TypeActionSelector | 已实现（0.0.2） |
| F002 | [尺寸输入器](dimension-input.md) | DimensionInput | 已实现（0.0.2） |

每项规范分别标注用户确认的规则、已有实现事实和待评审建议。新增组件复用本目录入口，每个组件有独立文档，持续更新当前结论；形成原因和迭代范围见[规范建立记录](../../../../../docs/features/form/component-specification/v1/desgin.md)。

布局参考：[紧凑表单基础尺寸](compact-layout.md)记录已确认的字段、字形、间距、圆角、动作区和节点承载尺寸，供新增表单设计查阅；它与公共组件默认参数分别维护。

共用原则：

- 同一语义的控件保持结构、命名和事件规则一致，业务通过类型数据和回调接入。
- 优先节省横向与纵向空间；紧凑尺寸仍应保留可识别的图标、焦点和操作反馈。
- 组件负责交互和状态展示；系统文件、媒体库、截图、权限、磁盘写入由应用提供。
- 保持纯 Flutter UI 包边界，不为了业务动作引入原生插件或依赖具体产品。
