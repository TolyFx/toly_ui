# F001 · 类型动作选择器

英文标识：**TypeActionSelector**。所属：**tolyui-form 通用表单组件**。

版本：v0.2 · 更新：2026-10-24。

状态：基础规则已由用户确认，Flutter组件已在当前源码中实现并导出，未发布新版本。当前实现参数如下，默认值仍可随规范讨论调整。

## 定义

把“选择类型”和“执行该类型对应动作”组合为一个表单控件。类型选择决定要执行什么，动作按钮执行一次对应动作。

## 已确认的结构与规则

- 左侧选择类型，右侧为动作图标，同一行、同一高度，共用外边框。
- 动作区仅显示图标，不常驻“选择图片”等动作文字；悬浮提示和无障碍名称说明动作。
- 动作图标随所选类型变化，类型标签继续显示。
- 点击动作图标执行对应动作。
- 提供 `autoTriggerOnSelect` 可配置参数：开启时，选择类型后自动执行一次对应动作。
- 组件归入通用表单规范，不绑定“图片输入节点”或某个固定业务。

## 参数约定

公开入口为 `TolyTypeActionSelector<T extends Object>` 和 `TolyTypeActionOption<T>`。选项字段为 `value`、`label`、`actionIcon`、`actionLabel`、`enabled`；下表记录当前实现。

| 参数 | 语义 | 状态 |
| --- | --- | --- |
| `options` | 可选类型；每项提供稳定值、类型名称、动作图标及动作提示 | 已实现 |
| `value` | 当前选中类型，与动作返回的业务结果分开管理 | 已实现，受控值 |
| `onTypeChanged` | 用户选中不同类型时通知业务 | 已实现，ValueChanged<T> |
| `onAction` | 执行动作，接收本次动作对应的类型 | 已实现，ValueChanged<T> |
| `autoTriggerOnSelect` | 选择类型后是否自动执行一次动作 | 已实现，默认 `false` |
| `enabled` | 控件是否允许交互 | 已实现，默认true |
| `actionEnabled` | 保留类型选择，只禁用当前动作 | 已实现，默认true |
| `actionRunning` | 展示由业务管理的动作执行状态 | 已实现，默认false |
| `density` / 主题 | 复用包内密度与主题能力 | 已实现，默认compact |

类型值应稳定且唯一，展示文案可以本地化。业务结果（图片、文件路径、截图内容等）不作为类型值塞入此控件。

## 自动触发事件规则

以下规则已由Flutter交互测试覆盖。默认关闭为本轮实现选择，后续可调整。

| 操作 | 类型变化通知 | 执行动作 |
| --- | --- | --- |
| 初始化、恢复草稿、外部回填值 | 不发用户变更通知 | 不执行 |
| 用户切换为不同类型，自动触发关闭 | 一次 | 不执行 |
| 用户切换为不同类型，自动触发开启 | 一次 | 一次，先完成类型更新 |
| 重复选择当前类型 | 不通知 | 开启时执行一次；点击图标也可再次执行 |
| 点击动作图标 | 不修改类型 | 一次 |
| 修改自动触发开关 | 不修改类型 | 不执行 |
| 动作取消或失败 | 保留选中类型 | 不自动重试 |

自动触发是每次用户选择菜单项后执行一次（包括当前类型），不是组件生命周期内只触发一次。自动路径和手动路径应共用同一个动作入口，避免重复监听导致执行两次。回调应拿到这次选择的类型，不能读取异步结束时可能已变化的类型代替它。

## 状态与可访问性

- 类型区和动作区具有独立焦点；键盘可选择类型并执行动作。
- 纯图标动作提供当前动作的语义名称，默认不提供 Tooltip；仅用户明确要求时由宿主添加。
- 整体禁用时，两区都不可操作；仅动作禁用时，仍可切换类型。
- 宿主设置`actionRunning: true`时，保留原动作图标，不展示 loading，两区都不可操作。宿主负责实际异步操作及取消/错误处理；组件不接管业务Future，也不自行重试。
- 没有合法类型时动作不可执行，提供可理解的占位提示。
- 窄容器中优先保留动作区域，类型文字可省略并保留完整提示。
- 悬浮使用主题反馈，不出现突然切换的默认灰底。

## 尺寸与主题

复用现有 `TolyFormThemeData` 和 `TolyFormDensity`。现有包的紧凑高度为28、常规高度为34；CatPic Web 的24px高度和26px动作区只是当前业务设计稿，不直接升级为公共规范固定值。当前实现动作区宽26px、文字11px，可通过`actionWidth`与`fontSize`配置；高度、背景、焦点色和圆角复用主题。示例用主题把紧凑高度设为24px。

## 第一个业务映射：图片来源

| 类型 | 动作 | 图标语义 |
| --- | --- | --- |
| 系统文件 | 选择系统文件 | 打开文件 |
| 媒体库 | 从应用媒体库选择图片 | 媒体库 |
| 截图 | 启动截图 | 截图 |

该表只是应用配置示例，公共组件不内置这些类型，不访问 CatPic 媒体数据库，不自行申请截图权限。当前 Web 设计稿中系统文件可选图，媒体库和截图仍为说明用途的设计入口。

## 验收清单

- 两区保持单行、同高、统一边框，动作仅显示图标。
- 切换类型后，动作图标和语义名称同步更新。
- 默认关闭/开启自动触发的两种状态都可配置。
- 自动触发只执行一次，手动点击也只执行一次，不互相重复。
- 初始化、状态回填和开关改变不触发业务动作。
- 取消和失败不改变已选类型，也不自动重试。
- 禁用、焦点、键盘及窄宽度有明确行为。
- 通用包没有新增产品依赖或原生能力依赖。

选择器位于缩放画布时，菜单宽度、行高及字号跟随锚点的实际屏幕缩放。

动作图标在可执行时使用主题激活色，禁用或执行期间使用禁用色。

选择器外框、动作分隔线和菜单边框统一使用 0.5 逻辑像素细线。

`typeBackgroundColor` 可独立配置类型选择区底色；为空沿用字段主题，右侧动作区保持字段底色。
