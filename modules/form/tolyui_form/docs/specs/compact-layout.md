# 紧凑表单基础尺寸

- 更新：2026-10-25。
- 状态：CatPic工作流节点中已确认的设计参考，当前原生与Web已实现。
- 单位：100%画布倍率下的逻辑像素（Flutter）/CSS像素（Web）；画布缩放后的视觉尺寸不作为组件参数。

本表供后续节点表单设计复用，记录已确认实例的尺寸。公共组件仍通过主题与局部style配置；这些数值不覆盖全包默认值。新表单根据字段语义选用对应参考，尚未定义的控件单独设计。

## F002 · 数值输入与比例动作

| 部位 | 当前参考值 | 说明 |
| --- | --- | --- |
| 单字段宽×高 | **48×16px** | W/H两个字段采用相同尺寸 |
| 数值字号 | **7px** | 包括空值占位 |
| W/H前缀字号 | **7px** | 常驻短标签 |
| 字段圆角 | 3px | 比例动作反馈区同样3px |
| 字段左右内边距 | 各6px | 无额外上下内边距 |
| 前缀与数值间距 | 4px | labelGap |
| 两字段间距 | 6px | fieldGap |
| 比例动作区宽×高 | 16×16px | 与字段等高 |
| 比例图标 | 10px | 与动作区大小分别配置 |
| 字段与比例动作区间距 | 4px | 原生lockGap；Web现有布局有独立对齐修正 |
| 字段底色 | #F4F5F6 | 常态及禁用保持原底色，无默认边框 |
| 数值/前缀颜色 | #344050 / #939AA3 | 占位色#687586 |
| 激活色 | #3B82F6 | 工作流独立蓝色 |
| 光标 | 1×10px、圆角0.5px | 原生显式配置；Web光标蓝色，几何由浏览器绘制 |
| 文字选区 | #3B82F6，20%透明度 | 原生选区手柄为激活蓝 |

对应[TolyDimensionInput规范](dimension-input.md)。普通工坊仍为32px高、数值12px、前缀10px，不随节点紧凑样式改变。

## F001 · 类型动作选择器

| 部位 | 当前参考值 |
| --- | --- |
| 整行高度 | 20px |
| 类型与菜单字号 | 8px |
| 动作区宽度 | 20px |
| 动作图标 | 10px |
| 圆角 | 3px |
| 外框与分隔线 | 0.5px |
| 菜单宽度 | 与包含动作区的完整选择器等宽 |

对应[类型动作选择器规范](type-action-selector.md)。此控件与数值输入承担不同交互，当前高度分别为20px和16px。

## 节点承载区参考

以下属于宿主节点布局，公共表单不自动生成标题或状态栏：

| 部位 | 当前参考值 |
| --- | --- |
| 标题栏高度/字号 | 24px / 8px |
| 状态栏高度/字号 | 17px / 7px |
| 尺寸表单外边留白 | 左右6px、上0px、下4px |

节点随实际表单包裹宽度；优先收紧无意义留白。默认无Tooltip和loading，保留正常焦点、选区、禁用及键盘反馈。

## 维护方式

后续尺寸调整同时更新本表、对应组件规范中的产品实例，以及宿主节点规范；历史尺寸保留在迭代记录中。以上是设计参考，业务范围、比例计算及提交规则仍由组件规范和宿主负责。
