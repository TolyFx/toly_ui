## 0.1.0

- package 从 `toly_menu` 迁移为 `tolyui_menu`，统一 TolyUI 包命名。
- 保持 `TolyMenuController`、`TolyMenuEntry`、`TolyMenuAnchor` 和 `TolyMenuBar` API 不变。

## 0.0.6

- 使用 `TolyMenuController`、`TolyMenuEntry` 和统一浮层替换旧菜单实现。
- 移除与 `tolyui_navigation` 冲突的 `MenuItemView` 公开类型。

## 0.0.1

- 建立菜单模型、统一控制器、级联菜单浮层和桌面菜单栏。
- 支持鼠标、键盘、禁用项、分隔线、勾选状态和主题扩展。
